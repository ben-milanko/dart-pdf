DartPDF는 모든 작업이 기기에서 이루어지는 PDF 편집기입니다.

어떤 PDF든 열어 마크업하고, 양식을 작성하고, 서명하고, 내용을 교정하고, 페이지 순서를 바꾸고, 페이지의 텍스트와 이미지를 편집할 수 있습니다. 변경 사항은 원본 파일에 그대로 저장됩니다.

아무것도 업로드되지 않습니다. 계정도, 동기화도, 광고도 없습니다.

기능:

• 형광펜, 밑줄, 취소선, 자유형 잉크
• 도형, 화살표, 텍스트 상자, 메모, 스탬프
• 기존 텍스트 편집 및 이미지 추가
• 화면에서 가리는 데 그치지 않고 파일에서 해당 텍스트와 이미지를 실제로 제거하는 교정
• 양식 필드 작성(텍스트, 확인란, 라디오 버튼, 드롭다운) 또는 직접 추가
• 어디에나 배치할 수 있는 손글씨 서명과 인증서 기반 PAdES 디지털 서명
• 스캔한 PDF에 OCR을 적용해 텍스트를 선택하고 검색
• 페이지 순서 변경, 삭제, 새 파일로 내보내기
• 전문 검색, 텍스트 선택, 링크
• 두 버전을 나란히 비교
• 암호로 보호된 파일 열기

Android, iPhone, iPad, Mac는 물론 Windows, Linux, 웹에서도 실행됩니다. 파일 관리자, 공유 시트, 드래그 앤 드롭으로 PDF를 엽니다. 밝은 테마와 어두운 테마를 지원합니다.
