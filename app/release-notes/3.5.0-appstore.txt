New in 3.5.0

- Large and highly detailed PDFs stay responsive while scrolling, panning, and zooming, and sharpen the visible area first.
- Page previews now progress through clearer detail levels during fast navigation.
- Pages no longer soften or briefly disappear near viewport edges.
- Faster remote document loading, with more predictable memory use.
- Developer tools can switch live between Canvas and the optional GPU tile backend and report detailed rendering diagnostics.
