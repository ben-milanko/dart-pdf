# Public marketing assets

This directory contains approved screenshots and media used by the app,
website, public listings, and package metadata.

- `app/`: app screenshots, including localized versions.
- `example/`: SDK example screenshots.
- `motion/`: reproducible promotional media, public storefront assets, and
  recording instructions.

Preserve existing asset paths and public URLs when updating these files.
Internal campaign plans, growth measurements, unpublished outreach, and store
submission receipts are maintained separately from this public source tree.
