# Review of PRs #926–#938

Reviewed the five merged PRs on main. Numbers #929–#936 are open feature
issues, not pull requests; implementing those features was outside this review.

## Findings fixed

- **#938: stale page indices during a drag (P1).** A same-count page edit,
  including undoing a reorder, leaves Flutter's reorder recognizer active.
  Releasing the drag could then transfer the page now occupying the grabbed
  slot. The strip records the starting document and cancels drops and reorders
  if the document changes.
- **#938: source changes during the native lookup (P1).** The asynchronous
  destination lookup allowed a page edit or source-window close before export
  and removal. The coordinator now checks source ownership and document
  identity before completing the transfer. Cancelled transfers clear the marker.
- **Thumbnail cancellation (P2).** Pointer cancellation cleared the external
  marker but left the multi-selection companion thumbnails dimmed. Clear the
  strip's drag state as well.
- **#927: signature guidance (P2).** Re-encrypting after signing invalidates the
  signature. DocMDP P=1 prevents additional approval signatures in the signing
  API, but the general editing APIs do not enforce certification permissions.
  The guide now distinguishes cryptographic integrity, trusted identity, and
  permitted changes, and removes the invalid re-encryption workflow.

No additional actionable findings in #926 (tab search/initial scroll), #928
(desktop activation), or #937 (adaptive memory). Reviewed their implementation
and existing regression coverage, including the Windows and Linux runner diffs.
