Extract PDF pages into a new file.

Send just the pages someone needs. Use the Pages panel in the desktop browser editor to export a selection while keeping the original PDF.

Open DartPDF in your browserGet the desktop app

Save selected pages

  1. Open your PDF in DartPDF's desktop browser editor.
  2. Open the Pages panel.
  3. Click the first thumbnail you need, then Shift-click the last thumbnail in the range. To keep pages 2 and 3, click page 2 and Shift-click page 3.
  4. Check that the selection count is correct, then choose Export selected pages.
  5. Open the downloaded PDF. Check its page count, order and contents, then give it a distinct filename if needed.

Check the exported copy

Printed page numbers can keep their original values. A two-page exported PDF may still display page labels 2 and 3 inside the document. Use the viewer's page count as well as the printed labels when checking the result.

The browser may add a number to the filename when you export more than once. Open the newest download rather than an earlier copy.

What page extraction does not do

Page extraction is not redaction or a metadata-cleaning tool. Do not use it as proof that sensitive information has been removed from a file.

Keep any digitally signed original separately. The extracted document is a new file, not the original signed PDF.

Need to send the whole PDF?

Reduce the PDF's file size instead. Start lossless and inspect a separate saved copy before sharing it.
