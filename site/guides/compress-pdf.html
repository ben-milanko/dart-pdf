Compress a PDF without uploading it.

Make a PDF easier to send while keeping the original. DartPDF processes the file on your device, including in the browser.

Open DartPDF in your browserGet the desktop app

Reduce the file size

  1. Open your PDF in DartPDF.
  2. Open the app menu and choose Reduce file size….
  3. Start with Lossless. This preserves image resolution and quality.
  4. Run the optimisation and compare the before and after sizes.
  5. Choose Save copy…, keep a distinct filename, and open the saved PDF to check it.

If the PDF is still too large

Image-heavy scans may need a quality trade-off. Screen, eBook and Print use different image resolutions and JPEG quality levels. Try eBook first if you need a smaller image-heavy file, then zoom into small text and drawings in the result.

Lossless compression cannot guarantee a smaller file. A PDF that is already compact may change very little. Lower-resolution settings can lose fine image detail; keep the original if that detail matters.

Where the copy goes

In the desktop browser, saving downloads a PDF or opens the browser's save-location prompt. Check Downloads if you cannot find it. On desktop, choose a writable folder. Review your platform's destination before closing the editor.

Keep a digitally signed original separately. Rewriting a PDF can affect signature validity; a smaller copy is not a replacement for the original signed file.

Remove pages instead of reducing image quality

If the recipient needs only a few pages, export those PDF pages to a separate file. Check that the new file contains exactly the information you intend to send.

Keep a copy you can check.

Open the result and check the pages before sharing it. Your original file stays available.
